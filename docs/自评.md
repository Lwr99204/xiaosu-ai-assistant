## 取舍与不足

项目采用 SQLite/Chroma 与本地 BGE-M3，降低部署复杂度但增加新机器准备成本；企业微信依赖社区 SDK。没有鉴权、OCR、多租户和供应商冗余。不同模型共用同一 OpenAI-compatible Base URL，不宣称为不同供应商。
